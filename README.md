# 🧭 טיולי נפתלברג - מה בסביבה | Naftalberg Trips - What's Nearby

אפליקציית WEB מתקדמת ורספונסיבית (Single Page Application) למטיילים ותיירים, הפועלת בעברית מלאה (RTL) ומותאמת במיוחד למכשירי סמארטפון (iPhone / Android) ומחשבים.

האפליקציה מתבססת על **מיקום חי (GPS)**, **מזג אוויר בזמן אמת**, ו**שעון המכשיר המקומי**, ומאפשרת ארגון טיולים לפי תיקיות, הגדרת מלון ידנית, חישוב מרחקים מדויקים מהמלון (ברגל, תחבורה ציבורית ורכב), וגילוי מיידי של אטרקציות, מופעים, מסעדות, בתי קפה, שירותים ציבוריים ושירותים חיוניים.

---

## ✨ מאפייני המפתח (Key Features)

### 📂 1. מסך תיקיות טיולים ומלונות (Trip Folders & Hotels)
- יצירת תיקייה נפרדת לכל יעד, עיר או חופשה (לדוגמה: רומא הקלאסית, פריז, ברצלונה, תל אביב).
- הגדרת פרטי המלון ידנית: שם המלון, כתובת, קואורדינטות והערות אישיות (קוד כניסה, שעות ארוחת בוקר וכו').
- שמירה מלאה ב-`localStorage` כך שהנתונים נשמרים תמיד בכל כניסה.

### 🕒 2. חלון עמוק: "איפה אני נמצא עכשיו?"
- **סנכרון מלא עם שעון ותאריך המכשיר (אייפון / דפדפן)**:
  - זיהוי אוטומטי האם האטרקציה פתוחה כרגע לפי שעת המכשיר (`🟢 פתוח עכשיו` / `🔴 סגור כעת - ייפתח מחר`).
  - לוח שעות פתיחה שבועי מלא עם הדגשת היום הנוכחי.
- **מופעים, אירועים ופעילויות להיום באתר**:
  - פירוט מופעי תאורה, מזרקות, חילופי משמר, וסיורים מודרכים לפי שעות.
- **פרטים, היסטוריה וסיפורים מעניינים**:
  - אנקדוטות היסטוריות וסודות מרתקים שלא כולם מכירים.
  - מדריך קצר: מה עושים כאן ונקודות צילום מובילות.
- **מחירי כרטיסים**:
  - מחירי כרטיס רגיל, מוזל, כניסה חינם ותוספות.
- **קישור לאתר הרשמי** וניווט מהיר ב-Google Maps.

### 🏨 3. מעקב מרחק מהמלון (Hotel Tracker)
חישוב אוטומטי בזמן אמת של המרחק וזמני ההגעה מנקודת המשתמש הנוכחית אל המלון שהוגדר בתיקייה:
- 🚶 **ברגל**: זמן הליכה משוער (דקות), קילומטרים וספירת צעדים.
- 🚌 **בתחבורה ציבורית**: זמן משוער בקווי מטרו / אוטובוס וטיפ מסלול.
- 🚗 **ברכב / מונית**: זמן נסיעה משוער והערכת עלות מונית במטבע מקומי (€ / ₪).
- כפתור ניווט ישיר ל-Google Maps.

### 🍽️ 4. גילוי מה בסביבה (Nearby Explorer)
חלוקה מהירה לקטגוריות ברורות:
- 🍽️ **מסעדות בסביבה**: דירוג, סגנון קולינרי, מחיר, שעות פעילות ומרחק.
- ☕ **בתי קפה בסביבה**: קפה איכותי, מאפים, מרחק ודירוג.
- 🚻 **שירותים ציבוריים בסביבה**: מידע קריטי למטיילים: מרחק, נגישות לנכים, חינם/בתשלום, ודירוג ניקיון!
- 🔍 **מה עוד באזור**: בתי מרקחת (פארם), סופרמרקטים, כספומטים/המרת כספים, תחנות מטרו ותחבורה.

### 🌦️ 5. ווידג'ט מזג אוויר חי בזמן אמת
- חיבור ישיר ל-Open-Meteo API ללא צורך במפתח API.
- מציג טמפרטורה, תיאור מצב השמיים בעברית, לחות, רוח והמלצת לבוש והתנהגות מותאמת אישית למטייל.

### 🗺️ 6. מפה אינטראקטיבית (Leaflet Map)
- סיכת משתמש פועמת באנימציית רדאר חיה.
- סיכת מלון מוזהבת וקו מסלול מהמשתמש למלון.
- סיכות צבעוניות לפי קטגוריות עם פופאפים מפורטים.
- סימולטור נקודות ציון מובילות (רומא, פריז, ברצלונה, תל אביב) לבדיקה קלה גם מהמחשב הביתי לצד GPS חי.

## 💻 הפעלה מקומית (Quick Start)

### דרישות מוקדמות
- דפדפן אינטרנט מודרני (Chrome, Safari, Edge, Firefox).
- Node.js (גרסה 16 ומעלה).

### הרצה
1. הורידו או שכפלו את הפרויקט:
   ```bash
   git clone https://github.com/rachel-naftelberg/naftalberg-nearby.git
   cd naftalberg-nearby
   ```
2. הפעילו את השרת המקומי:
   ```bash
   node server.js
   ```
   או בחלונות: לחצו פעמיים על הקובץ `start_app.bat`.
3. פתחו את הדפדפן בכתובת:
   [http://localhost:3005](http://localhost:3005)

## 📁 מבנה הפרויקט

```
naftalberg-nearby/
├── index.html              # שלד האפליקציה המרכזי (SPA)
├── css/
│   └── style.css           # עיצוב מלא: Glassmorphism, RTL, רספונסיביות
├── js/
│   ├── app.js              # הבקר הראשי המחבר את כל המודולים
│   ├── data.js             # מאגר נתונים עשיר (אטרקציות, שעות, מופעים, מקומות)
│   ├── folders.js          # ניהול תיקיות טיולים ומלונות עם localStorage
│   ├── weather.js          # חיבור ל-Open-Meteo API והמלצות מזג אוויר
│   ├── hotel-distance.js   # חישוב מרחק וזמני הגעה מהמלון (הליכה, תחב"צ, רכב)
│   ├── location.js         # מנוע GPS חי וסימולטור נקודות ציון
│   ├── attraction-modal.js # מודל מעמיק עם סנכרון שעון המכשיר, מופעים ומחירים
│   ├── places.js           # סינון והצגת מסעדות, בתי קפה, שירותים וציוד
│   └── map.js              # מפה אינטראקטיבית (Leaflet)
├── server.js               # שרת סטטי עצמאי ומהיר ב-Node.js
├── start_app.bat           # קובץ הפעלה מהיר בלחיצה כפולה למשתמשי Windows
└── README.md               # תיעוד הפרויקט
```
